# Contributing

External contributions are **not accepted yet**.

TopherLabs LLC offers this software under both the AGPL-3.0 and a commercial license. To keep that possible, every
contributor must sign a contributor license agreement (CLA) before any contribution is merged.

Before opening the repository to pull requests:
1. Have counsel review a CLA (start from an established template rather than writing one from scratch).
2. Set up automated CLA signing on pull requests.
3. Update this file with the process.

Issues and discussion are welcome once the repository is public.
